MVP: Astronaut Physiological Baseline Forecasting

Objetivo:
Predecir la evolución de una variable fisiológica individual durante un horizonte temporal definido y cuantificar su desviación esperada respecto al baseline previo a la misión.


Una variable objetivo: frecuencia cardíaca.

Un baseline individual calculado con mediciones previas a la misión.

Un conjunto de mediciones temporales durante la misión.

Un modelo de predicción.

Una visualización del baseline, los valores observados y la predicción futura.

Una estimación de incertidumbre.

Un indicador de desviación respecto al baseline.
